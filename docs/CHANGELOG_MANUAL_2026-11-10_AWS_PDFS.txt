CONFIGURACION PROPUESTA PARA EJECUTAR EN AWS
1. Region: us-east-1, igual que el backend desplegado.
2. Bucket: nombre globalmente unico a determinar en la cuenta AWS (ej.: boscochat-archive-<account-id>-use1).
3. Bloquear acceso publico en los cuatro ajustes del bucket; Object Ownership = Bucket owner enforced.
4. Versionado activado; cifrado SSE-S3 por defecto (SSE-KMS solo si se aprueba el coste y gestion de claves).
5. Permitir subida/listado al rol de ingestion y GetObject al rol de backend unicamente sobre prefijo autorizado, aplicando minimo privilegio.
6. No servir PDFs con URLs publicas o prefirmadas directamente desde el navegador: el backend autenticado autoriza y media las lecturas.
7. Organizacion: originals/<publicacion>/<ano>/<numero>/<nombre>.pdf, con claves estables y metadatos normalizados en MySQL; tratar nombres reales, caracteres especiales y colisiones.
8. Guardar inventario con bucket/key, SHA-256, tamano, publicacion, numero, fecha, estado de ingesta y errores.
9. Subida inicial desde el equipo del propietario con AWS CLI usando credenciales temporales SSO o un perfil de menor privilegio, nunca claves en repositorio:
   aws s3 sync "/ruta/al/archivo" "s3://NOMBRE_BUCKET/originals/" --dryrun
   aws s3 sync "/ruta/al/archivo" "s3://NOMBRE_BUCKET/originals/" 
   NOTA: la sincronizacion simple no incorpora por si sola metadatos catalograficos; no asumir que el path local cumple el esquema de organizacion.
10. Validar recuento, tamano y SHA-256 de cada PDF. Reintentos, logs e identificacion de duplicados.
11. Extraer capa de texto/OCR por pagina, preparar indexacion y registrar relaciones documento/pagina/fragmento.
12. Implementar endpoints autenticados para busqueda y visualizacion; probar que S3 deniega acceso anonimo y que el usuario no puede saltarse autorizaciones.
13. Revisar coste de almacenamiento, peticiones, OCR, indices y transferencia; habilitar alertas de presupuesto.
14. Evaluar retencion, recuperacion, backup y tratamiento de datos personales si los documentos o sus metadatos los contienen.
