# Cybersecurity role

Generic AppSec/security-review role for software delivery teams. It is intentionally project-agnostic. Project-specific risk appetite, architecture, compliance and deployment context belong in repository policies/profile files, not in this role.

Recommended invocation points: requirements/design for abuse cases, every PR in FAST mode, high-risk PRs/releases in FULL mode, and DEEP mode on explicit request or elevated risk.
